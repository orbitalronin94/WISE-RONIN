# WISE-RONIN independent capability corpus

Generated by `generate_wise_ronin_capability.py` from a verified checkpoint
manifest, a small curated factual bank, and deterministic arithmetic/logic
procedures.

## Files

- `wise_ronin_capability_all.jsonl`: all generated unique examples.
- `wise_ronin_capability_train.jsonl`: training split only.
- `wise_ronin_capability_validation.jsonl`: validation split, never trained.
- `wise_ronin_capability_holdout.jsonl`: untouched capability holdout.
- `wise_ronin_identity_manifest.json`: facts verified against the 50k parent
  checkpoint and tokenizer.
- `wise_ronin_capability_report.json`: actual unique counts and limitations.

## Quality rules

- No artificial expansion to a nominal 25,000 rows.
- No repeated question/answer loops to inflate counts.
- No KOAN boilerplate, generic moralejas, or automatic irony.
- Arithmetic is calculated by Python integer algorithms.
- Logic examples expose their premises and use explicit set membership.
- Identity facts come from the actual checkpoint configuration and tokenizer.
- Candidate facts overlapping the existing expanded corpus are filtered.
- Splits are assigned by stable `group_id`, not individual row IDs.
- The holdout file is never passed to the trainer.

The row count is not presented as the number of new world facts: synthetic
math/logic tasks are counted separately from curated factual anchors.
