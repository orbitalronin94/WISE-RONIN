# WISE-RONIN expanded factual and formulaic corpus

This dataset is generated by `generate_wise_ronin_expanded.py` and is intended
to replace the old template-heavy 70 MB corpus for future experiments.

## What it contains

The generator builds a deterministic 147,627-row JSONL from:
- A built-in bank of 402 canonical factual anchors: geography, chemistry
  (element names, symbols and atomic numbers), science, history, literature,
  units and stable general knowledge.
- Exact arithmetic questions with programmatically calculated answers.
- A varied Spanish style bank: 20 answer openers, 40 dry/trolling tails,
  20 object motifs, and 20 KOAN formulas. The fact is always stated first or
  explicitly inside the KOAN; the style must not replace the answer.
- 120 prompt formulations per canonical factual anchor and up to 10 per
  arithmetic question.

The generator enforces unique user prompts and unique literal assistant
responses. It does not append random hashes or arbitrary suffixes to force
uniqueness. The report records any style-formula collision repairs.

## Read the counts correctly

The number of JSONL rows is not the number of independent facts. Each row
contains:
- `fact_id`: stable grouping key for the underlying fact or arithmetic task.
- `variant_id`: paraphrase/style variant index.
- `tipo`: factual category or arithmetic operation.
- `hecho`: answer anchor that must remain present in the assistant response.
- `formula_salt`: deterministic alternate formula selected only to avoid
  literal duplicate answers.

Use `fact_id` for train/validation splitting and evaluation. Never randomly
split individual rows: that would leak paraphrases of the same fact across
train and holdout.

The generated report includes total rows, unique prompts, unique responses,
independent fact IDs, factual anchor count, arithmetic base count, and category
counts. This is a compact synthetic curriculum, not an external encyclopedic
corpus. The 402 general factual anchors should be expanded with separately
curated and cited sources before claiming broad factual coverage.

## Validation and safety

The GitHub Actions workflow:
1. Compiles and runs the generator.
2. Checks the exact target row count.
3. Requires 100% unique prompts and 100% unique literal responses.
4. Verifies every answer anchor appears in its target.
5. Checks that factual and arithmetic categories have meaningful volume.
6. Commits the generated JSONL and report to this branch and uploads an
   artifact.

The manual 500-question holdout is not read by the generator or workflow.
No training is started and no checkpoint is changed.
