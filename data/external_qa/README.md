# WISE-RONIN — Literal Questions / Manual Answers

This dataset applies one deliberately strict rule: **the question is copied literally; the answer is authored anew by hand**.

## Non-negotiable rules

1. \`question_verbatim\` must match the source string exactly. No cleanup, translation, punctuation repair, or paraphrase.
2. \`ronin_answer_manual\` is a new human-authored answer, not an automatic paraphrase.
3. The meaning must remain equivalent to the source reference answer, grounded in the exact context.
4. Keep source dataset, pinned revision, split, source ID and exact question. The pinned source queue retains the full context, reference spans and offsets.
5. Only original \`train\` rows may be admitted to training. Dev/validation/test remain evaluation-only.
6. No answer is generated by the importer. Unanswered questions remain an authoring queue, not training data.
7. A manually authored answer must be reviewed before export. The validator rejects pending rows and exact copies of reference answers.

## Current status

- SQAC train source pinned to commit \`9a6e701a8487c35c1805f9f29eac247875a6be05\`.
- 15,036 train questions are available from the source; the GitHub Actions workflow downloads and verifies the source SHA256 before producing an authoring queue artifact.
- \`sqac_manual_answers.jsonl\` contains **168 manually authored and reviewed examples**. It is not a full rewritten corpus and must not be presented as one.
- The compact manual file stores only source identity, the literal question and the new answer. Context and reference spans are recovered from the pinned queue during validation, avoiding repeated copies of long source passages in Git.
- ESQAD EVAU is registered as the next curated source. Its generated literary/legal/pilot subsets are not mixed with EVAU.
- SIQA-es and OpenBookQA-es are explicitly excluded from training in this pipeline.

## Build the question queue

\`\`\`bash
python scripts/build_literal_qa_queue.py --download \\
  --output build/sqac_train_authoring_queue.jsonl
\`\`\`

The queue is an Actions artifact, not committed training data. It contains exact source questions, contexts and reference answers, with an empty \`ronin_answer_manual\` field.

## Validate and export manual answers

\`\`\`bash
python scripts/validate_literal_qa_dataset.py \\
  --input data/external_qa/sqac_manual_answers.jsonl \\
  --source-queue build/sqac_train_authoring_queue.jsonl \\
  --sft-output build/sqac_manual_sft.jsonl
\`\`\`

The export is accepted only when every row is \`source_split=train\`, has \`author_status=manually_reviewed\`, matches the exact question and metadata from the pinned queue, preserves answer offsets, has a unique source ID, and contains a non-empty Ronin answer distinct from the reference answer.
